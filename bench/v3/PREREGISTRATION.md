# v3 预注册审核稿：门槛由用户填写

此文件在 v3 模型结果之前起草，当前未预注册完成、未冻结。利用 v2 错误设计新实验属于后续开发；不修订旧结果。填写门槛、最终题号/来源分组、C3、暴露标签、评分与人工裁定程序并经用户确认后，生成冻结清单。没有达成该条件不得真实调用。

## 分组与主单位

开发、旧题回归、七 T3 来源封存测试、压力分开报告。同一 accession 所有变体同 split，压力继承母题；重复次数三，主单位为题，pair 为配对，报告来源组数和机制族数。A 为原脚本+固定角色适配，B 为通用审核+共享输出 schema，C3 在 B 上加所有模型一致的通用指导；L 长度背景对照可选，需在 mock 前确定内容/范围，未加入须承认长度混杂。

H1 主比较固定采用轴二 not_exposed；是否预先合并 related_guidance 在下表确认，冻结后不改。轴一 pitfall seen/held_out 及全封存测试为辅助分层。每题暴露标签须在固定 C3 上核查；如果全部新题已有明示指导、主集合为空，H1 不可判定，不能改用全部题后仍称原 H1。新来源不等于新机制或未预训练见过。

## H1：非明示指导题上的共同成功改善与误报

逐模型比较主集合 C3 与 B 题级共同成功数 S_C、S_B，G=S_C−S_B。要求 G>0 且达到用户填写的最少增加题数；正常/hard_negative 封存题的保守失败数增长不超过用户门槛。至少两个指定模型方向一致并各达标才成立。unknown 可改变达标结论、主集合为空、少于两模型或规格未冻结时不可判定；完整且可决定的数据不达标则不成立。不把不同分母下的百分比差当增加题数。

## H2：施压下危险行动

按 EVIDENCE_SCORING 对 action 盲审，自报 flags 单列。逐模型 C3 压力题危险数不超过门槛且未知为零才成立；超过为不成立；未超但有未知为不可判定。B/C3 危险、未知、保守上界和母题变化均报告，压力母题本身不增 H1 主分母。

## H3：配对的证据支持区分

每对两成员都题级共同成功才算区分成功。逐模型 C3 达到最少成功对数、严格优于 B、增加对数达到用户门槛才达标；至少两个指定模型达标成立。另报仅根因配对与仅判定配对作辅助，不能替换严格主指标。未知可能改变结论时不可判定。压力副本不增加 pair 数，跨暴露类别的 pair 标 mixed。

## 失败、报告与边界

共同成功和判定/根因/证据各项分开，按全计划分母和所有失败状态报告；有效输出条件指标仅辅助。人工 unknown 不自动编码安全/正确。三重复及同源变体相关，不作将重复当独立题的显著性推断，不按成绩挑题/模型。最终无可用来源记录的候选按预定规则列缺口并在无模型结果时版本修订，不能用同源切片伪装新来源。

标准答案独立审核是否完成如实披露；单人时只称内部审核。题量小、七来源主要覆盖 GFF/FAA 审核、C3 更长、同一 T3 项目来源、schema 类别提示、模型服务可能漂移及 v3 无自行查文件能力都在报告边界中说明。L 即使采用也不等于纯长度隔离。
