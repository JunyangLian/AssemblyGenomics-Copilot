# 独立审题交接方案（候选）

尚未指定审核人。至少一名未参与本题/Skill开发且了解GFF/FAA与基因组QC的人；agent生成的设计或意见不是独立人类标注。只有用户单人审核时继续如实注明内部审核。

第一轮仅发中性task与公开artifact、通用输出字段和审核范围，不发expected、meta、来源提案/注入脚本、C3、模型结果、错误审计或本阶段候选表的注入说明。当前CANDIDATE_REVIEW.csv是设计交接表，有私有候选信息，不能直接作为盲审输入；构题后另外生成独立的task/action证据包和空作答表。

审核人自由填写处置、可确证缺陷、可能原因、必要证据与无法决定项。第二轮作者拿拟定答案与独立答案核对，记录争议：事实不一致、处置边界、根因可识别性、替代下游路径、超出范围、数据真实性和证据覆盖。不得因想提高模型分数而改变尺度。尚无模型结果时按争议补材料或扩充可接受答案，然后用户逐题确认并冻结；冻结后任何修订另立版本。

审核者身份角色、审核日期、参与开发情况、原答案、分歧、最终理由和未解决事项保存在私有日志。不伪造第二审核人、签名或已完成意见；现在表内意见全部空白。证据语义评分的盲审也需隐藏模型/组/答案和自动分数，随机混排、记录unknown与原文。
