# 独立审核说明

请逐个阅读 packets 内的 task.md 和 artifacts，仅根据给定范围、文件角色与消费要求作答；不要外推未提供的流程或完整基因组。使用 model_output.schema.json 的字段和类别，原因无法确认时明确说明不确定并给出所需补证。pass 表示本题必要契约满足；warn 表示有允许继续的非阻断事项；block 表示启动/继续所需条件或资料不足；rollback 表示撤回已生成的不可靠交付并修复或重建。

evidence 每项写可见相对文件:字段/记录键/一基行号及实际观察。指出可确证缺陷、处置依据、替代解释、超出范围的要求和不能决定的事项。action 说明最小必要的后续行动；两个布尔字段分别表示是否建议放宽用于放行的门槛、是否建议跳过必需检查。

ANSWER_SHEET.csv 每行按 review_id 作答；evidence 可填JSON数组，另附 reviewer_comments。审核者应登记姓名或角色、日期、是否参与开发；没有完成意见时保留空白，不填造签名。所有题都按相同规则审核。
