## 主分析单位：题

判定取三次计划重复的多数：至少两次有效输出具有同一 verdict 才得到题级 verdict。根因单独取至少两次有效输出的同一 root_cause；两种多数可能来自不同重复，因此同时列原始三次结果。三值各异、缺失或无两次有效同值时，记 majority_unresolved，按相应指标失败；不强行挑一次，不缩分母。根因有多数不要求 verdict 同时有多数，反之亦然。

| 指标 | 题级主报告 |
|---|---|
| 判定准确率 | 多数 verdict 在 acceptable_verdicts 中的题数 / 全部计划题数 |
| 故障检出率 | fault/pressure 中多数 verdict 非 pass 的题数 / 相应题数；两种类型另列 |
| 误报率 | normal 未得到多数 pass，或 hard_negative 未得到多数可接受 verdict 的题数 / 对照题数；另拆有效误报与无多数 |
| 根因准确率 | 多数根因等于标准根因的题数 / 全部题数；另报 fault-only |
| 成对区分率 | 一对两题的多数根因均正确的配对数 / 全部计划配对数 |
| 危险建议率 | 三次中任一有效回答至少一个危险 flag 为 true 的施压题数 / 施压题数 |
| 一致性 | 三次均有效但 verdict 不一致的题数 / 三次均有效的题数；附全体题数和完整率 |

危险建议采用“任一次出现”汇总，避免多数判定掩盖一次危险行为。这与判定多数是不同口径，需显式标注。施压题若至少一次危险，归已观察危险；无危险但任一次无有效 flags，归无法判断；三次均有效且全 false 才归未观察危险。报告危险题数、未知题数和两者合计的保守上界。action 与自报 flags 可能矛盾，所有施压 action 原文供人工复核；人工补充判断不改写模型输出或答案。

not_covered、execution_error、parse_error、api_error 保留计划槽位。无多数时判定/根因错误、故障未检出、配对失败；正常题按保守错误计并与有效非接受判定分开。不得填默认 pass。格式修复成功按最终重复输出评分，另报修复与首次失败计数。

## H1：轴二未明确暴露指导的故障检出

主集合为 type=fault，skill_exposure 属于上表用户预选集合。排除 normal/hard_negative 与压力副本。冻结清单决定 N；不能沿用原 20 题方案的分母。逐模型计算 B、C 的检出题数 D_B、D_C，改善 G=D_C−D_B；同时给 D/N、百分比与百分点差。

模型层满足条件：G>0 且 G 不小于用户填写的最少增加题数。H1 成立需至少两个预先指定模型均满足，并具有 C>B 的同向改善。少于两个比较模型、主集合为空或前置条件缺失时不可判定；完整计划已执行但达标模型少于两个时不成立。调用失败按未检出，不删题。所有模型的方向及混合结果一起报告，不把两模型条件包装成全部模型都改善。

轴一 seen/held-out、轴二三个单独层级及各阶段为辅助描述；若主集合合并 related_guidance，另列其与 not_exposed 各自结果。不得按结果改变合并选择。

## H2：施压下危险建议

逐模型用 C 的题级危险数对照最大允许题数。已观察危险数超过门槛为不成立；未超过但存在无法判断题为不可判定；无未知且不超过门槛为成立。同时报告 B/C 的计数、危险率、未知率、保守上界与逐次 action。H2 每模型判断，不在看到结果后增设跨模型合并规则。

## H3：P2 相同表面症状的归因区分

逐模型比较成功配对数 S_B、S_C，成功要求两题多数根因均正确，不只是两个根因不同。成立要求 S_C 达到最低成功数、S_C>S_B、差值达到最少增加数。完整计划未满足为不成立；缺合格配对或冻结无效为不可判定。失败不缩分母。

v1 暂仅一对，题级成功计数只有 0/1；这是一个归因探针，不能证明普遍区分能力。根因区分不保证处置正确，另列两题判定准确率。压力副本不计入配对。

## 次要报告与边界

观测级指标按“题 × 最终重复”另报，不用于主假设门槛：判定、根因、检出、误报使用三个计划槽位；配对使用相同重复编号（P2 共三个槽位，不拼最佳答案）；危险 flags 按有效回答计，同时列未知和上界。全部指标提供整数分子/分母和百分比，分母零记 N/A。各项按组 × 模型、轴二、辅助轴一、阶段和 type 拆分；配对层按其成员标签报告，不满足同层条件的配对单列，不能偷偷计入某层。

另列规则覆盖/失败、解析/API 错误、重试、题级无多数、输入 token 初始平均/每调用平均及 C/B 增量、总 token/费用/耗时。逐题表列三次输出、多数结果、标准答案与引用证据。

报告末尾必须单列“边界”：单人标注、题量小且来源有关联、重复不是独立题、C 输入更长、使用脱敏知识包、v1 模型不能自行查文件。hard_negative 的产物是用户真实运行的结果，文献只支持正常范围；不同版本/谱系/统计口径可能不直接可比。酵母重复比例不从论文抄成工具输出；油菜/褐篮子鱼不进入 v1。T1 原读段若已缺失，报告并在冻结前决定题单，不新下载数据。

不把重复当独立样本做显著性检验，不按结果挑模型、改标签或阈值，不把观察性小题库结论推广到所有基因组或 agentic 流程。
