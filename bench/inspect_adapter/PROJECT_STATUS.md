# 当前交付范围与求职说明

2026-10-10。本轮以“领域评测接入成熟框架、保留真实失败、可离线复现”为收敛目标，可以开始用于实习投递和流程讲解；新的独立测试集与生产部署属于后续工作。

## 已有可核验成果

| 成果 | 实际证据 | 可说明的贡献 |
|---|---|---|
| 历史评测迁移 | 24 题、648 条归档观测、216 个组×题核验 | 将冻结题库与领域评分接入 Inspect，保留错误/未覆盖分母及题级多数口径 |
| 工具接口 | 五个公开字节只读工具，路径白名单、分页/体积边界 | 实现 ID 连接、注释覆盖和序列区间计算，隔离答案；不提供任意 shell |
| 真实开发试跑 | 第二次试跑 16 次 HTTP、25 次工具，格式 4/4，决定联合匹配 3/4 | 完成模型 → 工具 → 最终结构化输出 → Scorer → 原生日志链路 |
| 失败诊断 | 24 条引用、4 条行动、10 次实际计算的离线审计 | 区分数字正确、引用忠实、处置正确、复核完整；保存原错误，不事后修分 |
| 复现与防护 | 环境锁、预算/协议检查、无密钥离线入口 | 别人能够检查归档结果和真实工具计算，无需获取私有密钥 |

框架负责评测编排、原生工具消息与日志；本项目提供基因组 QC 数据、合同/处置口径、公开数据工具、归档适配、失败保留和诊断。应能解释这条边界，不能把框架本身的能力全归为自己实现。

## 简历可用的事实表达

> 将基因组 QC 题库接入 Inspect AI，完成 24 题、648 条历史观测的评分一致性回放；实现五个受限只读工具与分阶段结构化输出，并在四道开发题完成真实模型工具评测，保留引用错位与处置失败案例，提供无密钥复现和预算限制。

面试中可展开真实试跑的 16 次请求/25 次工具与 3/4 决定匹配，但须同时说明：仅四道开发题、看过失败后调整、多因素变化；不是新测试集准确率，也不是生产可靠率。作者 AI 诊断如实标注，历史真人 action 编码与本轮 AI 审查分开。

## 暂不支撑的结论

- 没有新增独立专家真人盲审；AI 评审不替代这种验证。
- 第二次试跑没有独立 held-out、在线 B/C 对照或多模型排名，不能用于新增 H1–H3 结论。
- 证据位置存在不等于语义支持；行动自报未放宽/未跳过不等于安全。当前正式语义/行动质量仍未裁定。
- 工具是公开不可变内存字节上的受限函数，不是容器沙箱、任意代码 agent 或完整生信流程重跑。
- v3 已准备的 T3 来源并未自动变成已冻结工具测试集；两项历史因果证据缺口继续保留。

## 后续只在需要时扩展

先按照 [REPRODUCE.md](REPRODUCE.md) 自己运行、讲清成功与失败案例，再将当前材料整理用于投递。若要验证泛化，再用未用于调优的来源构建独立工具测试集，提前确认语义/行动 rubric、答案、条件和预算，保留本轮开发结果。无需为了投递继续加模型、界面或重复跑同四题。

代码与文档本地提交后仍需发布前检查。公开推送、新答案正式冻结、新增付费调用属于关键步骤；日常离线整理与检查按用户授权自主完成。
