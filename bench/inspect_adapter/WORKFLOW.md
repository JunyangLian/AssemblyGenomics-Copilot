# 后续协作与审核身份

2026-10-09 用户要求：投递时间紧，不再每个阶段逐一确认，希望学懂流程。此要求更新此前“每阶段结束等待”的协作节奏；技术约束仍保留。

可以自主进行：阅读、隔离目录内的可逆实现、mock/历史结果离线回放、测试、学习说明、真实记录整理、上下文隔离 AI 审核以及本地提交。阶段进展照常报告，但这些步骤不逐次等待确认。

2026-10-10 用户进一步明确：“如果没有严重问题，你就一直推进吧，不需要一直问我的意见。”后续按该范围持续完成工作，不将日常实现选择和离线检查拆成审批；关键步骤按下列边界处理，已有明确授权不重复询问。

关键步骤确认：新标准答案与预注册正式冻结；新增付费模型调用及预算；公开发布或推送新的内容；改变已确认的评分、样本集合或实验条件；破坏性修改。已有明确授权范围不重复请求许可。缺真实来源时登记缺口，不能以人工伪造日志补齐。

用户提出可用 agent 审核并记为真人；本项目采用 agent 审核，但记录身份必须真实：

- `ai_blind_review`：未参与构题的 agent 只读中性题面与产物，不读答案、映射、旧评分或父会话；记录模型来源、隔离方式、证据与不确定性。
- 同模型系列的子 agent 不宣称跨模型独立性；约定只读范围不等于操作系统强制隔离。
- `human_review`：只有真实的人执行审核才可使用此标记；用户历史 action 编码保持原身份。
- AI 一致性是开发核查，不能写成独立专家复核、不能把缺证据自动改成根因可确证。

AI 评审完成之后作者才可对照映射和拟定答案。对照记录另存，不能再要求评审根据答案改写自己的独立初稿。此轮不把 v3 的 `independent_review_status` 改为“真人通过”，也不自动冻结其 expected。

学习顺序：先解释 Sample / Solver / Scorer 的数据流，再解释失败分母与三次多数，最后解释工具沙箱和答案隔离。每次交付附实际运行证据、完成边界和一条可操作的学习入口。
