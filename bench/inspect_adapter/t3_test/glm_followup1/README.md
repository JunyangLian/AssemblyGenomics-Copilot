```shell
python -m bench.inspect_adapter.glm_followup fixture
```

fixture使用httpx2.MockTransport走原生Inspect供应商线路，永远不访问网络或读取真实密钥。固定合法输出只检验协议，不代表模型成绩；最大采集轮数与工具回复完整验证，另用更长真实GFF工具回复检查预算提前阻断。FIXTURE_RECEIPT.json记录当前实现与计划哈希。
