## 关键发现

1. **CDS 数 ≠ 基因数**：RefSeq GFF 的 CDS 特征数（含 isoform 拆分）可达基因数的 3-25 倍（如 zebrafish 54K gene → 1.3M CDS），基线校准应以 **gene 数**为准
2. **全基因组加倍（WGD）效应**：Salmon 82K 基因（WGD 后）、Brassica 50K（WGD 后）显著高于同科非 WGD 物种
3. **蛋白中位长度梯度**：线虫 < 植物 < 真菌 < 鱼类 < 昆虫 < 鸟类 < 哺乳类（192→538）
4. **内部终止/歧义字符**：25 物种全部为 0（RefSeq 审编集，质量一致）

## 对 AssemblyGenomics Skill 的意义

这 25 物种实测数据是基线带从**单案例锚定**升级为**群体校准**的第一步。
今后新物种进来时，基线判断不再依赖单个参考案例的猜测，
而是有群体分布做支撑——这正是"可靠性决策系统"的核心：每个判定都有群体证据。
